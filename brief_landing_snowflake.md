# Brief de Proyecto: Landing Page "Snowflake Training Path"

## 1. Contexto y Objetivo
El objetivo de este proyecto es construir una landing page interactiva y de alto impacto para cualquier persona que quiera preparar la certificación **SnowPro Core (COF-C02)** desde cero, utilizando recursos 100% gratuitos y oficiales.

La página debe estar diseñada con un enfoque hiper-pragmático, eliminando el "ruido" académico innecesario y yendo directo a lo que genera valor y retorno de inversión (ROI) en el tiempo de estudio.

## 2. Material Base y Licencias Creativas
Te voy a proporcionar un documento base llamado `Snowflake Training Path.docx` que contiene los enlaces y la estructura inicial. 

**Tienes total libertad (licencia creativa) para reestructurar, corregir y complementar el contenido basándote en el siguiente análisis crítico:**
*   **Ajuste de Prioridades:** El módulo de "Snowpark y Python" es valioso para el rol, pero secundario para *este* examen específico. Muévelo a una sección de "Bonus Track" o "Siguientes Pasos".
*   **Inclusiones Obligatorias (Faltantes en el doc original):** 
    *   Seguridad, Gobernanza y RBAC (jerarquía de roles).
    *   Pipelines (Snowpipe, Streams & Tasks).
    *   Protección de Datos (diferencia clara entre Time Travel y Fail-safe).
    *   Data Sharing avanzado.
    *   Enlace al "Study Guide" oficial en formato PDF como checklist final.

## 3. UI/UX: El Mapa Gamificado (Core Feature)
La experiencia principal de la landing debe emular un mapa de progreso de videojuego (estilo tablero con hitos, toma como referencia visual el concepto de `image_ff2967.jpg`). 

*   **Ruta Visual:** Un camino curvo que conecta diferentes "islas" o "niveles".
*   **Nodos Interactivos:** Cada hito en el mapa representa un bloque de estudio (ej: Nivel 1: Conceptos Básicos -> Nivel 2: Hands-On Labs -> Jefe Final: Pruebas de Práctica).
*   **Gamificación:** Al hacer clic en un nodo, se debe desplegar la información, los links de YouTube/Snowflake y los objetivos clave (qué temas caen en el examen).

## 4. DESIGN_PREFERENCES
*   **Estética:** Limpia, técnica pero accesible. Usa una paleta de colores moderna (inspirada en los azules gélidos de Snowflake, contrastando con colores cálidos para los botones de acción).
*   **Tono:** Directo, al grano y orientado a resultados. Nada de introducciones largas; la gente viene a buscar una hoja de ruta clara para certificarse y mejorar su perfil técnico.
*   **Navegación:** Todo el "Path" debe visualizarse en una sola pantalla con scroll, manteniendo el mapa gamificado como el eje central.

## 5. Elementos de Cierre y Comunidad
Al final del recorrido (o al marcar todos los hitos como completados), se deben mostrar las siguientes secciones:

1.  **Share to LinkedIn (Call to Action):** Un botón vistoso que genere un post automático con el texto: 
    > *"¡Completé el path de preparación para el SnowPro Core siguiendo el roadmap de Luca Lamorte! Listo para la certificación ❄️🚀"*
    *(Debe incluir una mención/enlace a mi perfil de LinkedIn).*
2.  **Apoyo al Creador:** Un botón o sección de donación muy amigable estilo **"Invitame un Cafecito ☕"** para quienes encontraron valor en la guía.
3.  **Feedback Loop:** Un formulario rápido (o enlace a Google Forms) para dejar sugerencias, reportar links caídos o comentar si aprobaron el examen usando el roadmap.
